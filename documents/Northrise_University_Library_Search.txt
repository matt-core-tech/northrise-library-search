Northrise University Library Search System with Categorization and Ranking

This project was created as part of the Algorithms and Data Structures course to show how data structures and algorithms can be applied in a real system. The main goal was to design a simple digital library that allows users to upload and search for academic text files related to algorithms and data structures. The system provides search results that are ranked and categorized, helping students find relevant materials easily. It was built using Python and the Tkinter library for the graphical user interface (GUI).

The program allows the user to upload .txt documents and then automatically indexes them using an inverted index. When a user types a query, the system searches through the indexed words and displays results that match the query. It supports both single-word searches and Boolean searches using “AND” or “OR”. The search results are then ranked using the TF-IDF (Term Frequency–Inverse Document Frequency) method, which gives higher scores to documents that contain important and rare words related to the query. This ensures that the most relevant documents appear at the top of the results.

The system was designed to be easy to use and understand. When it starts, it automatically creates a folder called sample_docs with ten ready-made text files that cover different topics such as linked lists, stacks and queues, trees and graphs, hash tables, and dynamic programming. The user can upload their own text files or use the sample ones. The GUI has clear sections including a search bar, a results list, a category filter, and a preview panel where users can read the contents of the selected document. It also highlights searched terms inside the document to make them easier to locate.

The main data structure used in the project is a dictionary, which acts like a hash table to store the inverted index. This structure maps each word to the documents in which it appears, making searches very fast. Counters are used to count how many times each word appears in a document, and sets are used to handle Boolean operations like AND and OR when combining search results. Lists are used to sort documents based on their TF-IDF scores. These structures work together efficiently and make the system simple but powerful.

For the TF-IDF ranking, the system calculates how often each search word appears in a document (term frequency) and how rare that word is across all documents (inverse document frequency). The higher the TF-IDF score, the more relevant the document is to the query. For example, if a user searches for “stack AND pop”, the system finds documents that contain both terms and then ranks them by relevance. The results are displayed in descending order with their scores and tags.

Each document is also automatically categorized. The system analyzes each file and finds its three most frequent words that are not common stopwords (such as “the” or “and”). These words are used as tags or categories for that document. Users can filter search results by these categories through a dropdown menu. For example, a document about binary trees might be tagged with “tree”, “node”, and “search”. This makes it easy to group and explore documents by topic.

During development, there were a few challenges. The first was text normalization, since words with different cases or punctuation were treated as different. This was solved by converting all text to lowercase and removing punctuation before indexing. Another challenge was parsing Boolean queries so the system could understand AND and OR correctly. A simple parser was written to detect these keywords and combine search results properly. Ranking documents accurately was another issue at first, but adding the TF-IDF formula fixed that problem. Finally, creating meaningful categories was tricky, but selecting the top frequent words in each document worked well as a simple solution.

The system was tested using ten sample academic files, and the results were accurate and easy to interpret. Sample queries like “stack AND pop” or “graph OR tree” produced ranked results that made sense. The interface worked smoothly, and real-time search updates made it easy to test different queries quickly. The project met all the core requirements, including document upload, index construction, Boolean search, TF-IDF ranking, and category-based filtering.

In conclusion, this project successfully demonstrates how algorithms and data structures can be used to build a simple but effective library search system. It applies important computer science concepts like hashing, term frequency, inverse document frequency, and Boolean logic in a practical way. The system is efficient, well-structured, and easy to use. It also shows how Python and Tkinter can be combined to create a clean, interactive GUI application without much complexity. Overall, the Northrise University Library Search System achieves its goal of helping students find and explore academic resources through categorized and ranked search results.
